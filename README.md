# Рейтинг+ (ratingplus)

Маленькое клиентское приложение (React + TypeScript + Vite): вводишь ссылку на **личную таблицу игрока** с chess-results.com — оно находит всех соперников, подтягивает их **национальные рейтинги из «Стартового списка»** турнира (для командных — из **«Составов команд без результатов туров»**) и считает, **на сколько пунктов изменится рейтинг ФШР** по результатам турнира — ещё до того, как официальный пересчёт появится на ratings.ruchess.ru (ФШР публикует его через несколько дней или даже недель после турнира, а результаты на chess-results.com — сразу).

Адрес приложения: **https://segodnyaev.github.io/ratingplus/**

## Ограничения

- Национальный рейтинг берётся такой, каким его показывает chess-results.com в стартовом списке (для командных турниров — в «Составах команд без результатов туров»; он должен соответствовать рейтингу на начало турнира — как и требует система ФШР).
- В командных турнирах составы команд не содержат номеров игроков, поэтому соперники сопоставляются по имени (проверено на Чемпионате России среди мужских команд — Премьер-лиге и командном блице: однофамильцы в одной команде различаются именем; коллизии полных имён практически исключены). Если у соперника рейтинга в составах нет, берётся рейтинг из таблицы партий (межд.), затем — 1000 как у новичка.
- Для соперников из других федераций колонка «Nat.» может означать рейтинг их федерации — формулу ФШР это волнует только в той мере, в какой chess-results её показывает.
- Если у соперника нет национального рейтинга, он считается имеющим 1000 (как новичок по правилам ФШР — так же делает и официальный пересчёт), что отмечается в интерфейсе.
- Официальный пересчёт появляется на ratings.ruchess.ru позже и может отличаться деталями (снятия, изменение рейтинга задним числом, неверно введённые стартовые рейтинги).
