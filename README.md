# Рейтинг+ (ratingplus)

Маленькое клиентское приложение (React + TypeScript + Vite): вводишь ссылку на **личную таблицу игрока** с chess-results.com — оно находит всех соперников, подтягивает их **национальные рейтинги из «Стартового списка»** турнира и считает, **на сколько пунктов вырастет (или упадёт) рейтинг ФШР** по результатам турнира.

Адрес приложения: **https://segodnyaev.github.io/ratingplus/**

## Ограничения

- Национальный рейтинг берётся такой, каким его показывает chess-results.com в стартовом списке (он должен соответствовать рейтингу на начало турнира).
- Для соперников из других федераций колонка «Nat.» может означать рейтинг их федерации — формулу ФШР это волнует только в той мере, в какой chess-results её показывает.
- Если у соперника нет национального рейтинга, он считается имеющим 1000 (как новичок по правилам ФШР), что отмечается в интерфейсе.
